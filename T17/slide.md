## Synthèse de ma veille technologique

- **Définition en une phrase :** MySQL est un système de gestion de base de données relationnelle qui permet de stocker et organiser durablement les données.

- **Problème résolu pour le projet :** MySQL permet de conserver les articles du Blog de manière permanente, contrairement aux données temporaires stockées en RAM.

- **Mes 3 mots-clés :** SGBDR — SQL — PDO sécurisé.
